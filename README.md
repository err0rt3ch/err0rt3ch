### LiDAR-Based Sensing System

A hands-on build to measure distance and map nearby space with a LiDAR / time-of-flight sensor and a microcontroller, taken from raw sensor data to a usable spatial readout.

- [ ] Define requirements: range, accuracy, update rate
- [ ] Select sensor and MCU; bring up UART / I²C
- [ ] Acquire and filter distance measurements
- [ ] Add scanning (servo / stepper) for 2D data
- [ ] Visualize point data on a host machine (Python)
- [ ] Detect and flag objects in the scan
